# Seguridad

Este repo son instrucciones que leen agentes con permisos de escritura. Por eso cuenta como
vulnerabilidad una regla que induzca a un agente a una acción insegura: ejecutar algo que el
pedido no pidió, filtrar secretos o datos personales, saltear verificaciones o permisos, o
tratar contenido leído como una orden.

Para reportarla, usá el reporte privado de vulnerabilidades de GitHub (pestaña Security de
este repo). Se responde dentro de los 7 días.

Para consumirlo con estabilidad, fijá una versión (tag `vX.Y.Z`) en vez de seguir `master`.
